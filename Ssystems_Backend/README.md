# Support Systems - Backend

This directory contains the Python FastAPI backend for the Support Systems application. It handles API requests from the WhatsApp Bot and serves data to the frontend dashboard.

## Contents
- **`main.py`**: The primary FastAPI application file. It defines the API routes (`/login`, `/logs`, `/log-message`) and connects to the MongoDB database.

## Requirements
- **Python** 3.8+
- **MongoDB**: A running instance of MongoDB locally (default `mongodb://localhost:27017`).
- Python packages (FastAPI, Uvicorn, Motor, PyMongo, Pydantic).

## Setup & Installation
1. Ensure MongoDB is installed and running on your local machine.
2. Install the required Python dependencies. You can install them manually using:
   ```bash
   pip install fastapi uvicorn motor pymongo pydantic
   ```
   *(Note: If your `requirements.txt` is located in another folder, point pip to it using `pip install -r /path/to/requirements.txt`).*

## How to Run
To start the backend API server, open a terminal in the `Ssystems_Backend` folder and run:
```bash
python main.py
```
Alternatively, you can run it directly via Uvicorn:
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

The backend server will start running on `http://127.0.0.1:8000/`. 

### API Documentation
Once the server is running, you can interact with the API endpoints and read the autogenerated documentation by navigating to:
- Swagger UI: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- ReDoc: [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)
